Проект содержит Bash-скрипт `project-helper.sh`.

Скрипт:

* запрашивает название проекта;
* проверяет введённое значение;
* создаёт папку `reports`;
* создаёт несколько файлов;
* формирует отчёт о созданных файлах.

## Запуск

```bash
chmod +x project-helper.sh
./project-helper.sh
```

После запуска необходимо ввести название проекта.

## Результат

Результат работы скрипта сохраняется в файле:

`reports/report.txt`
