## 1. Проверка пользователя

Для проверки текущего пользователя и его групп были использованы команды:

```bash
whoami
id
groups
```

Текущий пользователь: `sergei`.

## 2. Создание файлов

Была создана папка:

```text
linux-permissions-practice/
```

В ней находятся:

```text
notes.txt
run.sh
```

## 3. Права файлов до изменения

Для просмотра прав была использована команда:

```bash
ls -la
```

Права файлов были проверены до изменения с помощью `chmod`.

## 4. Изменение прав `notes.txt`

Для установки прав `644` была выполнена команда:

```bash
chmod 644 notes.txt
```

Права `644` означают, что владелец может читать и изменять файл, а остальные пользователи могут только читать его.

## 5. Добавление права выполнения для `run.sh`

Была выполнена команда:

```bash
chmod +x run.sh
```

После этого у файла `run.sh` появилось право выполнения, обозначаемое буквой `x`.

## 6. Запуск скрипта

Скрипт был запущен командой:

```bash
./run.sh
```

Результат:

```text
Hello from run.sh
```

## 7. Результат работы

В результате были созданы файлы `notes.txt` и `run.sh`, проверены их права доступа и изменены права с помощью команды `chmod`. Скрипт `run.sh` был успешно запущен.
