# Проект представляет собой консольное приложение на Bash для работы с заметками.

После запуска `./app.sh` появляется меню, через которое можно добавлять, просматривать, искать и удалять заметки.

## Возможности

1. Добавление заметки.
2. Просмотр всех заметок.
3. Поиск заметки по слову.
4. Удаление всех заметок.
5. Выход из программы.

## Используемые средства

В проекте используются Bash, `while`, `case`, `read`, функции, переменные, `grep`, `cat`, `touch` и `chmod`.

Данные сохраняются в файле `data/notes.txt`.

## Запуск

Перед первым запуском необходимо выдать право на выполнение:

```bash
chmod +x app.sh
```

Запуск проекта:

```bash
./app.sh
```

## Обработка ошибок

Если пользователь вводит пункт, которого нет в меню, программа выводит сообщение:

```text
Неверный пункт меню
```
