## 1. Создание структуры папок

Была создана папка `linux-files-practice`, внутри которой находятся папки:

```text
linux-files-practice/
├── data/
├── logs/
└── reports/
```

Были использованы команды `mkdir`, `cd`, `pwd`, `ls`.

## 2. Создание и чтение файлов

В папке `data` были созданы два текстовых файла:

```text
file1.txt
file2.txt
```

Для создания использовалась команда `touch`.

Для чтения файлов использовались команды `cat`, `head` и `tail`.

## 3. Создание файла лога

В папке `logs` был создан файл `app.log`.

В него были добавлены строки с уровнями:

```text
INFO
WARN
ERROR
```

Для просмотра содержимого использовалась команда:

```bash
cat logs/app.log
```

## 4. Поиск строки через grep

Для поиска строки с ошибкой была использована команда:

```bash
grep "ERROR" logs/app.log
```

Команда нашла строку:

```text
ERROR: Application error
```

## 5. Поиск файлов через find

Для поиска файлов использовалась команда:

```bash
find . -type f
```

Были найдены созданные текстовые файлы и файл лога.

## 6. Подсчёт строк

Количество строк в файле лога было проверено командой:

```bash
wc -l logs/app.log
```

Результат:

```text
3 logs/app.log
```

## 7. Сохранение результата

Результат команды был сохранён в файл `reports/result.txt`:

```bash
wc -l logs/app.log > reports/result.txt
```

## 8. Использованные команды

```text
pwd
ls -la
cd
mkdir
touch
cat
head
tail
grep
wc -l
find
```

В результате была подготовлена рабочая папка `linux-files-practice` с данными, логом и отчётом.
